# كلمات قرآنية — لعبة كلمات قرآنية للأطفال والنشء

لعبة تعليمية مبنية على منهج «نحو جيل قرآني»: **6 محطات × 4 مراحل = 24 مرحلة** تغطي سور القرآن الـ114، والطالب يمشي فيها بالترتيب ويتعلم معاني القرآن وقصصه وقيمه سورةً سورة.

Next.js 15 (App Router) + TypeScript + PostgreSQL/Prisma، في تطبيق واحد. واجهة عربية RTL، Light فقط، Mobile-first، PWA.

## التشغيل

```bash
npm install
cp .env.example .env        # DATABASE_URL + ADMIN_EMAIL / ADMIN_PASSWORD (٦ أحرف على الأقل)
npm run db:deploy           # إنشاء الجداول
npm run db:seed             # المحطات والمراحل والسور الـ114 + أدمن + 6 مستويات نموذجية في المرحلة 1
npm run dev                 # http://localhost:3000  — لوحة المدرس على /admin
```

`npm test` (اختبارات المنهج، السور، الاستيراد، الألعاب، النقاط)، و`npm run typecheck` و`npm run lint` و`npm run build`.

> إعادة `db:seed` تمسح المحتوى والطلاب والتقدم وتعيد إنشاء المنهج والمحتوى النموذجي (وتحدّث كلمة مرور الأدمن من `.env`).

## إضافة الأسئلة (Excel)

لوحة التحكم ← **رفع Excel**:
1. **تنزيل القالب**: ورقة «الأسئلة» (كل صف = سؤال، بقوائم منسدلة)، ورقة «تعليمات»، وورقة «المراحل والسور».
2. **فحص الملف**: يُفحص الملف كاملًا ويعرض كل خطأ برقم الصف (سورة ليست من المرحلة، آية خارج النطاق، كلمة فيها مسافة، عدد أسئلة غير مناسب للشكل…). لا يُحفظ شيء ما دام فيه خطأ.
3. **استيراد**: المستوى الموجود بنفس (رقم المرحلة، رقم المستوى) يتحدّث، والجديد يُنشأ، والباقي لا يتغير. نتائج الطلاب على الأسئلة المحفوظة تبقى.

**تنزيل الأسئلة الحالية** يُخرج المحتوى بنفس الشكل لتعديله وإعادة رفعه. الكود في `src/server/import/` (`columns.ts` شكل الأعمدة، `parse.ts` الفحص، `excel.ts` القراءة والقالب، `apply.ts` الحفظ).

### قرارات مهمة
- **المسار العمري** بدل السنوات: الطفولة (7–11) / النشء (12–18). كل مستوى له مسار: الكل / الطفولة / النشء.
- **الترتيب**: المستوى يُفتح فقط بعد إكمال كل ما قبله في المنهج كله، والسيرفر يرفض نتيجة مستوى مقفول.
- **قياس المعارف**: كل سؤال له نوع (معنى مفردة / قصة وشخصيات / قيمة وسلوك / مقصد السورة / معلومة عن السورة) وسورة وآية. نتيجة كل سؤال تُحفظ في `ItemResult`؛ الإتقان = الإجابة الصحيحة من أول مرة بدون تلميح (آخر محاولة لكل طالب). التقارير حسب المرحلة والسورة والنوع، وأكثر الأسئلة خطأً.
- **الرسم**: الكلمة في اللعب بالرسم الإملائي (التشكيل وعلامات المصحف تُزال تلقائيًا)، والرسم العثماني اختياري في عمود «النص القرآني» ويُعرض في بطاقة المعلومة.
- **أشكال اللعب** لكل مستوى: 🎡 عجلة الحروف، 🔠 شبكة الحروف، 🔗 توصيل، 🧩 أكمل الكلمة. كل شكل chunk مستقل.
- **هوية الطالب**: اسم أول + مسار، و`anonymousId` في cookie httpOnly + localStorage، مع حفظ اختياري لرقم/بريد للاسترجاع.
- **النقاط على السيرفر**، و`clientAttemptId` يمنع احتساب المحاولة مرتين بعد انقطاع النت.
- **الأمان**: bcrypt، جلسات أدمن مُشفّرة في قاعدة البيانات، rate limiting، CSP صارم بدون نطاقات خارجية.
- **Supabase**: Session pooler (منفذ 5432) حده 15 اتصالًا. للإنتاج استخدم Transaction pooler (6543) مع `?pgbouncer=true&connection_limit=1`.
- **سيرفر تحقق ثانٍ**: `NEXT_DIST_DIR=.next-verify` يشغّل نسخة بمجلد بناء منفصل بدون التعارض مع `npm run dev`.
