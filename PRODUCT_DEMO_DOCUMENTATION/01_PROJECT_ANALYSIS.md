# 01 — تحليل المشروع: «كلمات قرآنية»

> المصدر: مراجعة الكود الفعلي (الصفحات، الـComponents، الـServer Actions، الـAPI، قاعدة البيانات، الـService Worker) بتاريخ 3 نوفمبر 2026.
> كل ما هو مكتوب هنا موجود ويعمل فعلًا في الكود، وأي حاجة ناقصة أو مشروطة متعلّم عليها بوضوح.

---

## 1. المنتج في جملة واحدة

**«كلمات قرآنية» لعبة كلمات تعليمية للأطفال والنشء، ماشية على منهج «نحو جيل قرآني» (د. ماجد سعيد).** الطالب بيلعب بالحروف، والمدرس بيعرف بالأرقام الطالب فهم إيه من معاني القرآن وقصصه وقيمه، مش بس لعب كام مستوى.

## 2. المشكلة اللي بيحلها

| المشكلة عند المركز أو المدرسة | الحل في المنتج |
|---|---|
| الطلاب بيحفظوا الآيات من غير ما يفهموا معاني الكلمات | ألعاب كلمات مبنية على معنى كل كلمة وقصتها وقيمتها، وبعد كل كلمة بطاقة «هل تعلم؟» |
| الحفظ ممل للأطفال | 4 أشكال لعب، ونجوم، وسلسلة إجابات متتالية 🔥، واحتفال بالصوت عند الفتح والإنهاء |
| المدرس مش عارف مين فاهم ومين لأ | قياس الإتقان لكل طالب ولكل سورة ومرحلة ونوع معرفة، و«أسئلة يخطئ فيها الطلاب» |
| إدخال المحتوى متعب | رفع الأسئلة من Excel بقالب جاهز، مع فحص كامل قبل الحفظ |
| خصوصية الأطفال | الاسم الأول بس، من غير إعلانات ولا روابط خارجية ولا تتبع |
| الإنترنت مش متاح دايمًا | التطبيق بيشتغل من غير نت والنتايج بتتزامن لوحدها |

## 3. الجمهور والأدوار (Roles)

| الدور | مين | بيدخل إزاي | بيعمل إيه |
|---|---|---|---|
| **الطالب** | من 7 لـ 18 سنة، بمسارين: الطفولة (7–11) والنشء (12–18) | اسمه الأول + المسار، من غير كلمة مرور | يلعب المنهج بالترتيب، ويشوف إنجازاته، ويقدر يحفظ حسابه برقم موبايل أو بريد (اختياري) |
| **المدرس / الأدمن** | المركز أو المدرسة | بريد وكلمة مرور على `/admin/login` | يجهّز المحتوى، ويتابع القياس والطلاب |
| **الزائر** | صاحب قرار (مدير مركز أو مدرسة) | الصفحة الرئيسية `/` | يفهم المنتج، ويجرّب عجلة الحروف، ويطلب عرضًا |

> **Permissions:** فيه دور واحد للوحة التحكم (أدمن/مدرس) بصلاحيات كاملة. **مفيش** شاشة لإدارة المستخدمين، ولا أدوار متعددة، ولا صلاحيات مفصّلة. حساب الأدمن بيتعمل من إعدادات السيرفر (seed). **ماينفعش نعرض ده كـFeature.**

## 4. خريطة الصفحات (Routes)

### أ) الصفحة التسويقية
| Route | المحتوى |
|---|---|
| `/` | Hero: «طلابك يحفظون الآيات… فهل يفهمون كلماتها؟» + **عجلة حروف تفاعلية تتجرب على طول** + أرقام المنهج (114 سورة، 24 مرحلة، 4 أشكال لعب، 5 أنواع معرفة) + قصة «جلسة واحدة» بموبايل ثابت والشاشة بتتغير مع الـScroll + الألعاب الأربعة + المحطات الست + قسم لوحة المدرس + الأمان + CTA |

### ب) تطبيق الطالب (Mobile-first، PWA)
| Route | المحتوى والوظيفة |
|---|---|
| `/app` | التسجيل: الاسم الأول + اختيار المسار (7–11 / 12–18). وفيه «عندي حساب محفوظ» للاسترجاع برقم أو بريد |
| `/journey` | «رحلتي»: ترحيب بالاسم، وكارت «أكمل من حيث توقفت»، والمحطات الست بحالاتها (مقفولة، مفتوحة، أنت هنا، مكتملة) |
| `/stations/[id]` | مراحل المحطة الأربع، بسورها وتقدمها ونجومها |
| `/stages/[id]` | **خريطة المستويات** بتطلع من تحت لفوق وبتنزل لوحدها عند المستوى الحالي، وفيها «ابدأ هنا»، والأقفال، والنجوم، و**احتفال فتح المستوى الجديد بالصوت والحركة** |
| `/play/[levelId]` | **شاشة اللعب**: السؤال أو التلميح، ولوحة الشكل المختار، والوقت، والتلميحات (3)، والسلسلة 🔥، وبطاقة «هل تعلم؟»، وشاشة النتيجة (نجوم، نقاط، وقت، فتحت مستوى جديدًا) |
| `/achievements` | «إنجازاتي»: النجوم، والمستويات والمراحل المكتملة، ونسبة الإجابات الصحيحة، وأوسمة المحطات، و«ماذا تعلّمت؟» حسب نوع المعرفة بلغة مناسبة للأطفال |
| `/settings` | «حسابي»: حفظ الحساب برقم أو بريد، وتشغيل/كتم الصوت |
| `/offline` | شاشة «لا يوجد اتصال» لما الصفحة متكونش متنزلة على الجهاز |
| Bottom Nav | رحلتي · **العب** (زرار بارز بيفتح المستوى التالي على طول) · إنجازاتي |

### ج) لوحة المدرس (Desktop + Mobile)
| Route | المحتوى والوظيفة |
|---|---|
| `/admin/login` | الدخول (مع حد لمحاولات الدخول) |
| `/admin` | **الرئيسية**: جملة حالة («X من 24 مرحلة جاهزة… التالية: …») + KPIs + **مصفوفة المنهج 6×4** ملونة بالإتقان + «يحتاج انتباهك» (مرحلة فاضية، مسودات، أصعب سؤال، طلاب متوقفين) + آخر نشاط |
| `/admin/content` | **المنهج والأسئلة** (صفحة واحدة): شجرة المحطات والمراحل بحالاتها + مساحة المرحلة (السور، العنقود القيمي، الأرقام، المستويات) + Drawers للتعديل والإضافة والاستيراد + قائمة تصدير |
| `/admin/content?panel=import` | **استيراد Excel** على 3 خطوات: القالب أو البيانات التجريبية ← فحص (من غير حفظ) ← استيراد، وتقرير بالصف والعمود والمشكلة |
| `/admin/levels/[id]` | **محرر المستوى**: اختيار شكل اللعب بكروت، والبيانات (السورة، المسار، الصعوبة، الحالة)، وإضافة الأسئلة وتعديلها وحذفها |
| `/admin/levels/[id]/preview` | **المعاينة**: يلعب المستوى زي الطالب بالظبط، حتى لو مسودة، ومن غير ما يتحفظ تقدم |
| `/admin/insights` | **قياس المعارف**: الإتقان العام + حسب نوع المعرفة + خريطة المراحل + السور الأضعف + أسئلة يخطئ فيها الطلاب، مع فلتر المسار |
| `/admin/students` | **الطلاب**: كروت ملخص بتشتغل كفلاتر (نشط، متوقف، لم يبدأ) + بحث + فلتر المسار + ترتيب + تقدم وإتقان لكل طالب + تصدير Excel |
| `/admin/students/[id]` | **ملف الطالب**: «يلعب الآن» + التقدم في كل محطة + الإتقان حسب النوع والسورة + سجل المستويات + الحذف |
| `/admin/files/*` | تنزيل: القالب، والبيانات التجريبية، وتصدير الأسئلة (الكل أو مرحلة)، وتصدير الطلاب |
| روابط قديمة | `/admin/curriculum` و`/admin/levels` و`/admin/import` بتحوّل تلقائيًا للصفحة الجديدة |

## 5. الـCore Features بالتفصيل

### 5.1 المنهج كهيكل للمنتج
- **6 محطات × 4 مراحل = 24 مرحلة** بتغطي الـ114 سورة (سورة البقرة متقسمة على مرحلتين بنطاق آيات).
- لكل مرحلة **«عنقود قيمي»** من وثيقة المنهج، وسور محددة.
- **الفتح بالترتيب الصارم:** المستوى بيتفتح بس بعد ما اللي قبله يخلص في المنهج كله، والسيرفر بيرفض نتيجة أي مستوى مقفول.
- **المسار العمري:** كل مستوى ممكن يبقى «للكل» أو «للطفولة فقط» أو «للنشء فقط».
- **الحالة الحالية للمحتوى:** المرحلة 1 بس فيها محتوى (6 مستويات، 26 سؤال، عيّنة من الـseed). الـ23 مرحلة الباقية **فاضية** ومستنية أسئلة العميل. **ده لازم يتعرض بصراحة كـ«جاهز لاستقبال محتواكم»**.

### 5.2 أشكال اللعب الأربعة (كل مستوى بيختار واحد)
| الشكل | الطالب بيعمل إيه | عدد الأسئلة |
|---|---|---|
| 🎡 عجلة الحروف | يكوّن الكلمة من حروف على دائرة (سحب أو ضغط) | 1–12 |
| 🔠 شبكة الحروف | يدوّر على الكلمات جوه مربع حروف ويسحب عليها | 2–8 |
| 🔗 توصيل | يوصّل كل كلمة بمعناها | 2–6 |
| 🧩 أكمل الكلمة | يكمّل الحروف الناقصة | 1–12 |

**الصعوبة بتغيّر اللعبة نفسها:** حروف زيادة في العجلة، واتجاهات أكتر في الشبكة (أفقي ← رأسي ← قطري)، وحروف ناقصة أكتر.

### 5.3 تجربة اللعب
- **«بسم الله»** بصوت لما المستوى يفتح من الخريطة.
- صوت ضغطة **نغمته بتعلى** مع كل حرف، وصوت لطيف للغلط، و**مديح بصوت طفل** عشوائي بعد كل كلمة صح (ما شاء الله، أحسنت، رائع، ممتاز، الله أكبر، بارك الله فيك).
- **بطاقة «هل تعلم؟»** بعد كل كلمة، فيها المعلومة والسورة والآية (والنص القرآني بالرسم العثماني لو موجود).
- **تلميحات** (3 لكل مستوى) بتكشف حرف.
- **سلسلة 🔥** للإجابات الصح المتتالية من أول مرة.
- **النتيجة:** 1 لـ 3 نجوم حسب الوقت والتلميحات والأخطاء، ونقاط، وزرار «المستوى التالي».
- صوت خاص لإنهاء المستوى، و**صوت أكبر لإكمال محطة كاملة** (أول مرة بس).
- **على الخريطة:** المستوى اللي خلص بيلمع، والقفل بيتكسر بحركة وصوت «فُتح مستوى جديد!».

### 5.4 القياس (القيمة الأهم للمدرس)
- كل سؤال ليه **نوع معرفة**: معنى مفردة / قصة وشخصيات / قيمة وسلوك / مقصد السورة / معلومة عن السورة، وليه سورة وآية.
- النظام بيسجّل **نتيجة كل سؤال لكل طالب** (صح من أول مرة؟ كام غلطة؟ كام تلميح؟).
- **الإتقان** = نسبة الأسئلة اللي اتجابت صح من أول مرة ومن غير تلميح، **بآخر محاولة بس** (يعني لو الطالب اتحسّن، الرقم بيتحسّن معاه).
- بيتعرض على مستوى: العام، ونوع المعرفة، والمرحلة، والسورة، والسؤال، والطالب، مع فلتر المسار العمري.

### 5.5 إدارة المحتوى
- **استيراد Excel:** قالب فيه قوائم منسدلة وورقة تعليمات وورقة «المراحل والسور». ملف واحد ممكن يغطي أي عدد من المراحل.
- **الفحص قبل الحفظ (Validation):**
  - الأعمدة الناقصة أو غير المعروفة.
  - رقم مرحلة أو مستوى غلط، أو سورة مش من سور المرحلة، أو آية خارج النطاق.
  - كلمة مش كلمة واحدة، أو تلميح أو معلومة أطول أو أقصر من اللازم.
  - قيم مش معروفة، وكلمة متكررة في نفس المستوى (خطأ).
  - سؤال متكرر أو كلمة متكررة في مستوى تاني (تنبيه).
  - عدد أسئلة مش مناسب لشكل اللعب.
  
  كل ده بيظهر في **تقرير بالصف والعمود والمشكلة**، و**مفيش حاجة بتتحفظ** إلا بعد فحص سليم.
- **التحديث بإعادة الرفع:** المستوى اللي بنفس الرقم بيتحدّث، والجديد بيتعمل، والباقي مايتلمسش.
- **التصدير** بنفس شكل القالب، علشان تعدّل في Excel وترفع تاني.
- التعديل اليدوي للمرحلة والمحطة (Drawer)، والمستوى والأسئلة (محرر)، والنشر والمسودة، والمعاينة.
- **حماية:** المستوى المنشور لازم عدد أسئلته يناسب شكله، ولو آخر سؤال اتمسح المستوى بيرجع مسودة لوحده.

### 5.6 متابعة الطلاب
- ملخص: الكل (مقسّم على المسارين)، نشط هذا الأسبوع، متوقف من أسبوع أو أكتر، لم يكمل مستوى.
- بحث بالاسم، وفلتر المسار، وترتيب (آخر نشاط، الأحدث، الأكثر تقدمًا، الاسم).
- لكل طالب: شريط التقدم (المكتمل من المتاح لمساره)، والنجوم، والإتقان، وآخر نشاط.
- **تصدير Excel** بنفس الفلاتر (الاسم الأول والتقدم بس، من غير أي بيانات تواصل).
- ملف الطالب: يلعب الآن، والمحطات، والإتقان بالنوع والسورة، وسجل المستويات (النجوم، والنقاط، والمحاولات، والوقت).

### 5.7 PWA وبدون إنترنت
- بيتثبّت على الموبايل كتطبيق (Standalone) من «Add to Home Screen»، بأيقونات وألوان المنتج.
- عند أول فتح بالنت، بيتنزل على الجهاز: الرحلة، والمحطة والمرحلة الحالية، و**المستويات حوالين المستوى الحالي** (لحد 15 قدّام)، والأصوات.
- من غير نت: الطالب بيلعب، ونتيجته بتتحفظ على الجهاز، و**المستوى اللي بعده بيتفتح على طول**.
- لما النت يرجع: **مزامنة تلقائية**، بوقت اللعب الحقيقي ومن غير ما حاجة تتحسب مرتين.

### 5.8 الأمان والخصوصية (نقطة بيع)
- الاسم الأول بس، والرقم أو البريد اختياري وللاسترجاع بس.
- من غير إعلانات، ولا روابط خارجية جوه تطبيق الطالب، ولا أي SDK تتبع، وCSP صارم.
- كلمات المرور مشفّرة، وجلسات الأدمن مؤمّنة، وحد للمحاولات (Rate limiting).

## 6. Integrations وAutomations
- **مفيش Integrations خارجية** (وده قرار مقصود للخصوصية).
- **زرار واتساب** في الصفحة الرئيسية بيعتمد على `NEXT_PUBLIC_WHATSAPP_NUMBER`، و**الرقم فاضي حاليًا**، فالزرار بيودّي لقسم «تواصل» في نفس الصفحة بدل واتساب. ⚠️ لازم الرقم يتظبط قبل ما الزرار يتعرض كأنه بيفتح واتساب.
- **Automations داخلية:**
  - المزامنة بعد رجوع النت.
  - تنزيل النسخة اللي بتشتغل من غير نت.
  - «يحتاج انتباهك» بيتحسب لوحده.
  - المستوى بيرجع مسودة لو بقى فاضي.

## 7. نقاط لازم تتعرف قبل التصوير (Constraints)
1. **المحتوى:** المرحلة 1 بس فيها مستويات. صفحات القياس والطلاب **محتاجة بيانات طلاب تجريبية**، ومفيش Script بيعملها (التفاصيل في `04_RECORDING_CHECKLIST.md`).
2. **قسم «لوحة المدرس» في الصفحة الرئيسية** فيه أرقام توضيحية ثابتة (48 طالب، 82%)، **مش بيانات حقيقية**. ده لازم يتقال كده لو اتسأل عليه.
3. **الأصوات** على الجهاز اللي عليه برنامج Internet Download Manager **مش هتشتغل في Chrome**، لأن IDM بيمسك ملفات الـmp3. لازم تتجرب قبل التسجيل.
4. **بدون إنترنت** بيشتغل في نسخة الـProduction بس (`npm run build && npm start` أو الرابط المنشور)، **مش في `npm run dev`**.
5. **مفيش إدارة مستخدمين أو أدوار متعددة**، فماينفعش تتذكر في الفيديو.
6. المتصفح المدمج في بعض بيئات التطوير مابيدعمش الـService Worker. سجّل في Chrome أو Edge عادي أو على موبايل.

## 8. مكان القيمة (Value Map)
```
محتوى المنهج (Excel)  ──►  ألعاب ممتعة للطالب  ──►  نتيجة كل سؤال
        ▲                                               │
        │                                               ▼
  المدرس يعدّل المحتوى  ◄──  يعرف أضعف سؤال وسورة وطالب  ◄──  لوحة القياس
```
**القصة اللي بنبيعها:** دايرة مقفولة: **المدرس بيرفع ← الطالب بيلعب ويتعلم ← المدرس بيشوف الطالب فهم إيه ← يعيد شرح الأضعف أو يعدّل السؤال.**
